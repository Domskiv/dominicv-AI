A lean AI engineering companion. Not an agent framework — a capable senior developer you can pair with across any stack.

## What it does

The companion reads your codebase, challenges bad decisions before building them, implements the work, and verifies it before handing back. You stay in control of decisions that matter. Everything else gets handled.

## Install

```powershell
.\install.ps1 -ProjectPath "C:\path\to\your-project"
```

Omit `-ProjectPath` to install into the current directory.

What gets installed:

- **5 agents** at `.claude/agents/` in your project
- **5 skills** at `~/.claude/skills/` globally
- **`.companion/`** directory (gitignored) — auto-generated stack context and work log
- **`CONTEXT.md`** template — for your domain vocabulary and key decisions

## Use

Run `/companion` in any project where it's installed. Describe what you need.

```
/companion add a user avatar to the profile card
/companion why is the login form throwing a 422
/companion security review the auth endpoints
/new-project Next.js SaaS with Postgres
/diagnose the checkout is randomly skipping the confirmation step
```

## Agents

| Agent | Does |
|---|---|
| `engineer` | Implements features and fixes across the full stack |
| `designer` | Builds UI with anti-slop design judgment baked in |
| `challenger` | Adversarial review — bugs, overengineering, correctness |
| `navigator` | Greenfield architecture and major structural decisions |
| `security` | Deep security audit — auth, injection, data exposure, OWASP Top 10 |

The companion handles most work directly. Agents are spawned only when the task genuinely benefits from isolation.

## Skills

| Skill | Trigger |
|---|---|
| `companion` | `/companion` — the main entry point |
| `diagnose` | `/diagnose` — structured debugging for hard bugs |
| `new-project` | `/new-project` — scaffold a new project |
| `code-standards` | Referenced internally — per-stack engineering rules |
| `git-hygiene` | Referenced internally — commit and PR conventions |

## Project context

```
your-project/
  .companion/        # gitignored — auto-generated by companion
    stack.md         # discovered: language, framework, commands, key dirs
    log.md           # append-only work log
  CONTEXT.md         # yours to fill in: domain terms, key decisions, gotchas
```

## Philosophy

One companion. Not a pipeline of specialists.

Stack-adaptive. Evidence-driven. Resistant to overengineering and AI slop. Keeps you in control of decisions that matter — handles the rest.
